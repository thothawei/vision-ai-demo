# 系統導覽：品檢員的一天

本文件依「品檢員一天的操作流程」說明系統怎麼用。各功能的判定規則與常見誤判處理見 [user-guide.md](user-guide.md)，安裝與設定見 [admin-guide.md](admin-guide.md)。

> **版本說明**：目前版本（0.17.0）尚未提供使用者登入與工單選單，這兩項分別規劃於後續版本（使用者與角色、主檔與檢驗配方）。下列流程中標示「（後續版本）」的步驟，現況是在畫面上方的追溯資訊列手動填寫。

前置：`ollama serve` 已啟動、`uvicorn main:app` 已啟動、瀏覽器開 http://127.0.0.1:8000。啟動方式見 [README.md](../README.md#快速開始)。

## 1. 登入與選工單（後續版本）

目前：在畫面最上方的追溯資訊列填入工單號、料號、批號、站別、操作員。這組資訊會自動帶進之後每一次檢驗，並存進檢驗紀錄，供 ERP 與看板篩選。填寫內容為自由文字，大小寫不同會被視為不同工單。

## 2. 檢驗

依現場要檢什麼，切到對應分頁，上傳照片或按「📷 拍照」。一次選多張會自動走批次，結果以縮圖卡片呈現。

| 現場情境 | 使用功能 | 判定重點 |
|---|---|---|
| 標籤上有條碼／QR | 追溯碼辨識 | 解出批號、效期；已過期判 NG，30 天內到期標「即將到期」 |
| 外觀有無刮傷、缺角 | 外觀瑕疵異常檢測 | 只需良品照片訓練；熱力圖紅區為異常位置 |
| PCB 板 | PCB 瑕疵偵測 | 標出瑕疵類型與位置 |
| 零件數量、尺寸 | 計數與尺寸量測 | 數量與公差超出即 NG |
| 組裝有無漏裝、裝反 | 組裝防呆 | 與黃金樣本逐區比對 |
| 烤漆、陽極顏色 | 色差 ΔE | ΔE 超過門檻判 NG |
| 出貨標籤 | 出貨標籤比對 | 料號、數量、批號與工單預期值比對 |
| 危險區域、安全帽 | 危險區域入侵／安全帽偵測 | 人員進入畫定區域、未戴安全帽判 NG |

資料夾監控（`scripts/watch_folder.py`）可讓相機或掃描器把照片存到資料夾後自動檢驗。

## 3. 複判

1. 切到「品檢紀錄與看板」分頁，展開該筆紀錄，可看到原圖、標註圖與完整明細。
2. 若 AI 判定有誤，填入複判結果與備註送出。AI 判定與最終判定分開存放，不會被覆蓋。
3. 複判後，看板的「最終良率」與「AI／人工一致率」即時更新。良率計算排除 `INFO`（例如現場照片辨識、醫學影像展示），避免混入非品檢判定。

## 4. 看板

- 每日良率折線圖、NG 原因柏拉圖、各模組良率堆疊圖。
- 可依模組、日期、判定、追溯欄位篩選。

## 5. 匯出與 ERP 串接

- 「匯出 CSV」下載檢驗紀錄（含追溯與複判欄位，Excel 開啟中文不亂碼）。
- ERP 以 `X-API-Key` 呼叫 `/api/inspections?since_id=` 增量輪詢；NG 事件可設定 webhook 即時通知。細節見 [erp-integration.md](erp-integration.md)。目前驗證程度：C# 範例可編譯，尚未對真實 SQL Server 端到端實測。

## 6. 導入自有零件

1. 現場誤判 → 人工複判 → `scripts/export_reviewed.py` 匯出成 YOLO／MVTec 格式。
2. 以 Label Studio Community 校正標註。
3. 外觀異常檢測：在分頁「新增自訂類別」上傳良品（可含 NG）照片 zip，背景擬合，完成後以直方圖與滑桿調整門檻。
4. 監督式模型（PCB、安全帽）：以校正後標籤重訓，比較新舊指標，較佳才換上線。
