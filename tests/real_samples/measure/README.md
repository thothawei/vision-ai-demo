# 尺寸量測的真實照片：拍攝與標註流程

**目前沒有這個模組的真實照片。** 量測需要畫面中同時有 ArUco 標記（`DICT_4X4_50`）與一個已知尺寸的工件，公開網路上（Wikimedia Commons）搜尋不到合用的照片，所以 `docs/evaluation.md` 這個模組維持「待補真實照片」，沒有拿合成圖冒充。下面是自己拍的做法。

## 準備

1. 產生標記：`python scripts/make_aruco.py`，用雷射印表機以 **100% 大小**（不要「縮放至符合頁面」）印出，貼在平整的硬板上。
2. 用游標卡尺量印出來的標記**黑色方框的邊長**（至少量 3 次取平均），這個數值就是 `marker_size_mm`；不要直接用規劃的名義尺寸。
3. 工件用游標卡尺量長、寬各 3 次取平均，這是標註的真值；孔徑同理（可選）。

## 拍攝

- 工件與標記**放在同一個平面上**（例如同一張紙、同一塊板子），四周留一點空白，整個工件與標記都完整入鏡。
- 工件顏色與背景要有對比（黑工件白紙、或亮工件深色墊板都可以）。
- 用手機正上方拍，另外各拍幾張**斜拍 15°、30°、45°**，以及**不同光線**（日光燈、側光、有陰影）；每個條件至少 5 張，才有統計意義。
- 檔名要能看出條件，例如 `bracket_top.jpg`、`bracket_tilt30.jpg`。

## 標註（`labels.json`）

```json
{
  "device": "iPhone 15 手機相機；游標卡尺 Mitutoyo 500-196-30（解析度 0.01 mm）",
  "note": "工件：鋁板 50.02 × 19.98 mm（各量 3 次取平均）；標記實測 30.12 mm",
  "samples": [
    {"file": "bracket_top.jpg", "expected": {"長度mm": 50.02, "寬度mm": 19.98}, "tolerance": 1.0,
     "params": {"marker_size_mm": 30.12}},
    {"file": "bracket_tilt30.jpg", "expected": {"長度mm": 50.02, "寬度mm": 19.98}, "tolerance": 1.0,
     "params": {"marker_size_mm": 30.12}}
  ]
}
```

`tolerance` 是你能接受的絕對誤差（mm）。跑 `python scripts/evaluate.py --module measure`，結果會更新到 `docs/evaluation.md`。
照片若不能公開，請不要 commit（在 `tests/real_samples/measure/` 放 `.gitignore`），只在本機評估。

## 已知限制（拍之前先知道）

- 假設工件與標記**共平面**；工件有厚度、頂面比標記高時，會因透視而偏大，誤差隨厚度與斜拍角度增加。
- 標記只有一百多像素寬時，單一角點差一個像素就會讓比例尺偏約 1%（已啟用子像素細化）。拍近一點、讓標記占畫面較大比例，精度更好。
- 很重的陰影緊貼工件時，會被當成工件的一部分（實測：陰影灰度約 60% 且緊貼，寬度多約 1.4 mm）。
